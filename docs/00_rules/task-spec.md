# SMP 2026 星网干预赛题

**赛题背景：**

假设遥远深空存在一支高等外星文明，其文明意识依托**一定数量**（**初赛50节点，复赛100节点**）具备独立属性的神经元节点构成分布式星网。该网络正依靠节点间的信息传播与观点交融，最终集体表决对地球采取援助还是进攻策略。

本质上，本赛题是一个高度拟真的"**复杂社会网络中的关键节点识别与动态干预**"任务。参赛者需利用大语言模型的分析决策能力，组建一支基于casevo框架的智能体特种小队潜入该未知星网，进行侦察与干预，最大化外星文明对地球的援助意愿。

**核心任务与操作约束：**

星网初始对选手处于完全隐藏的**战争迷雾**状态。参赛智能体需在全局**固定精神力预算**（**初赛100精神力，复赛200精神力**）约束下，循环执行以下任务：

**1. 探索迷雾（消耗0.5精神力/次）**：扫描未知节点，获取其天生人设（和平/暴力/中立）、初始倾向值及其关联的所有有效邻接链路。

**2. 战术干预**：基于探明的局部图谱，智能体需精打细算精神力，实施以下三种干预操作改变网络初始状态：

- **策略游说 (消耗2精神力/次)**：从官方给定的话术库中选择预设策略（指定 prompt_id），对目标节点施加固定的数值倾向修正。修正效果受节点固有人设影响（例如和平节点易受正向影响，暴力节点极难被游说）。
  - 注：为防止单点无限刷分，同一节点最多仅能被游说3次，且收益严格边际递减（第2次衰减为50%，第3次衰减为25%）。
- **切断链路 (消耗3精神力/次)**：物理切断一对已知节点间的双向通信连线，阻断暴力节点负面观点的扩散。
- **全域屏蔽 (消耗5精神力/次)**：消耗高额预算，将极度危险的核心节点彻底剥离，直接从图网络中拔除。

**3. 推演结算**：当智能体预算耗尽或主动停机后，系统将接管干预后的图网络。所有存活节点将按照网络共识算法进行迭代演化（节点连接度数越高，观点保留能力与影响力越大）。

**4. 单种子得分计算**：推演收敛后，系统将计算该宇宙种子全网的综合援助意愿（即所有存活节点稳态值与其度数权重的乘积之和）。

**赛制规则与评测机制：**

- 指定开发框架：参赛程序必须接入官方指定的casevo多智能体框架进行逻辑编排，严禁使用单向静态执行脚本。
- 大模型算力：选手提交代码中驱动智能体的线上大模型API服务（智谱glm-4-plus）由主办方统一提供，无需选手承担费用（选手本地部署与测试除外）。
- LLM 调用上限：单个图网络种子中，初赛最多调用 LLM 120 次，复赛最多调用 LLM 250 次。早期 SDK README 与 `local_test.py` 中的 50 次为内测占位保护值，不是正式评测上限。
- 本地种子配置：`custom_seeds/my_test_network.json` 的 `global_setting.max_api_calls` 仅控制 `local_test.py` 的本地回合保护，可按自定义种子的规模修改；它不改变正式评测的 LLM 调用上限。
- 多窗口提交与结算：赛程划分为5个固定的时间段（初赛3个，复赛2个）。选手需提交 ZIP 代码包。主办方会在每个时间段截止时，取各队伍在该阶段的最后一次有效提交进行后台批量评测。
- 多宇宙种子泛化测试：为考验智能体在未知环境下的泛化能力，评测时系统将在后台的多个隐藏宇宙种子（不同的拓扑与人设分布）上运行选手代码，并取这些种子的综合援助意愿平均值作为该次提交的最终原始成绩。

**评分标准：**

本赛题采用动态天梯相对评分制：

**1. 完赛基准分 (30分)**：代码无崩溃，成功完成环境交互，且干预后的最终平均成绩 PlayerAvg大于或等于网络在无干预下的官方自然演化基准分 BaseAvg。

**2. 策略博弈分 (70分)**：系统动态计算全场队伍的最高平均成绩 PlayerAvg。选手得分根据其提升幅度进行线性映射计算：

![评分公式](https://static.tianchi.aliyun.com/tianchi/race/images/prod/532511/1818612140606782/nc03am6disslpovn.png)

$$
\mathrm{Score}
=
70 \times
\frac{\mathrm{PlayerAvg}-\mathrm{BaseAvg}}
{\mathrm{MaxAvg}-\mathrm{BaseAvg}}
$$

（若表现低于官方基准算法，该部分得分为0）

**3. 平局判定**：获得同等意愿Total的队伍，剩余未使用精神力多者排名靠前；剩余精神力相同，消耗API调用次数少者靠前。

**赛题样例**

本次比赛依托中国传媒大学媒体融合与传播国家重点实验室研发的多智能体社会传播模拟器框架casevo进行验证与评测。casevo致力于为社交传播和群体智能研究提供可灵活定制的轻量级基座。

**平台特点：**

1. **原生支持环境感知与动态状态机**：内置灵活的Environment交互接口，完美支持本赛题中"侦察-反馈-再决策"的不完全信息博弈机制。
2. **高效的多智能体拓扑编排**：提供极简的框架级API，方便参赛者快速搭建包含不同角色（如侦察分析、策略制定、指令执行）的多智能体系统。
3. **去中心化消息总线与记忆管理**：内置结构化上下文记忆，支持多智能体间低延迟的信息共享，助力算法在复杂网络中快速定位关键节点。

2. 固定接口与自由设计边界

**规则限定：**

- 主类名必须为ParticipantSquadModel，且必须继承casevo的ModelBase。
- 初始化函数__init__必须接收官方传入的host_env（环境 API）和llm（大模型实例）。绝对禁止在代码中硬编码或替换为自己的API Key，否则视为违规。
- 核心动作必须在step(self) 方法中实现，系统会循环调用该方法，直到您的精神力预算耗尽。

**选手自由设计：**

- 智能体架构：您可以在 config.json 中自由定义智能体的数量与分工（如：1个全能指挥官，或"1指挥+3侦察+1执行"的军团）。
- 提示词工程：自由设计prompt/ 下的文本模板，赋予智能体特殊的战略偏好。
- 决策算法：在 step() 中，您可以纯靠大模型决策，也可以在本地用Python维护一个 networkx 拓扑图，写A*或PageRank算法辅助大模型决策。

**3. Environment API 交互指南**

星网环境初始处于战争迷雾中，节点总数固定为50/100个（ID 范围 1-50，1-100）。官方的 host_env将为您提供以下交互API以打破迷雾并实施干预：

```js
# 1. 状态查询类
env.get_remaining_budget() # 获取当前剩余的精神力预算（float）

# 2. 侦察类（每次调用耗费 0.5 预算）
# 盲扫或顺藤摸瓜探索节点。若节点存在，返回其详细属性；若已被屏蔽或不存在，返回 None
env.scan_node(node_id: int) 
# 成功返回示例：{"w": 10.5, "persona": "和平", "comm_left": 3, "neighbors": [5, 12, 45]}

# 3. 干预类（返回成功状态，并自动扣除对应预算）
# - 话术游说（耗费 2.0）：prompt_id 可选 1, 2, 3，对应不同强度的修正值
env.communicate(node_id: int, prompt_id: int) 
# - 切断链路（耗费 3.0）：切断已知两节点间的连线
env.cut_link(u: int, v: int)
# - 全域屏蔽（耗费 5.0）：将高危节点彻底从图网络中踢出
env.shield_node(node_id: int)
```
