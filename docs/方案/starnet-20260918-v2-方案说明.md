# 星网V2：结构边际与剩余预算规划

原包用户反馈官方531.1233分；V2目标官方≥950，目前必须以新的官方评测验收。
原包不覆盖，新包为`submissions/starnet-20260918-v2.zip`。真实LLM验证结果统一
记录在[续研报告](../../research/starnet-strategy/report-v2.md)，不把自建种子分数当榜单分。

## 主要变化

原方案对游说使用增量×degree+1、对屏蔽使用负面负担；两个分值不能充分表示
删点后其他节点的影响变化，也未比较花掉5预算所放弃的游说。V2使用公开扫描
结果建立各连通分量，对每个合法屏蔽/切边假设重算图及影响权重。

经验分数代理为：

\[
\widehat S=\sum_C |C|\frac{\sum_{i\in C}(d_i+1)w_i}{\sum_{i\in C}(d_i+1)}.
\]

该式由38次小图单位响应和随后50节点自然/干预后官方沙盒结算验证，仍是有限
覆盖的近似，不能宣称掌握官方精确公式。人设响应系数与话术强度仍然隐藏。

## 预算规划

沿用同节点三话术反馈校准，除去第2/3次沟通的0.5/0.25衰减。每个节点仅提供
最强已测正向话术，最多12个不同目标，提高候选多样性。对目标的预测依次使用
同节点、同人设样本和跨人设先验，不把这些先验当官方系数。

对每个候选结构操作，计算立即边际`gain_proxy`，然后将余款可购买的各次游说
收益排序求和，得到`completion_advantage`：执行结构操作后再游说，相对直接
用全部剩余预算游说的预计最终优势。节点每次沟通的递减与剩余次数均纳入。

同时给出`robust_advantage`，表示未来游说收益为估计值0.5/1/1.5倍时的最差优势。
24种子实验表明强制按这个值过滤并不稳定，故仅给LLM作为风险证据。

## 决策与合规

单个CaseVO AgentBase指挥Agent调用官方注入LLM，决定候选编号与理由；传统算法
只整理观测和候选。完整扫描、校准和干预均受LLM计划授权。结构操作必须单独
执行，成功后清空旧计划并重算。无结构候选时可批准最多4个不同节点游说，扫描
最多8个。每步最多一个动作，执行前再次核查预算和节点/边有效性。

屏蔽不限于旧版w<-20且度数≥3；切边只涉及已扫描的两个端点及已知存在的边。
只能调用get_remaining_budget、scan_node、communicate、cut_link、shield_node；
没有读取隐藏图、反射透视、测试评分接口、个人凭证或替换注入LLM的代码。

120/250步与LLM调用分别计数。LLM坏JSON最多再问一次；超时停止，不启用纯算法
兜底。未确认的结构操作不更新观测图；测试客户端不重试可能已执行的状态变更。

## 实现与限制

- `src/starnet/policy.py`保留观测/话术学习与原候选基线，便于重现对照。
- `src/starnet/topology.py`实现纯Python图代理和预算候选，不含沙盒或LLM客户端。
- `src/starnet/model.py`编排CaseVO与合法动作，记录授权审计。
- 打包器合并上述模块为单个starnet_model.py，只携带配置与两份提示词。

已有官方自建12种子对照支持平均提升，但有个别退化；未来响应异质性、有限
迭代、LLM决策差异及未知隐藏分布均可能影响线上成绩。真实ZIP与算法控制分开
报告；官方GLM与隐藏多种子均分仍需平台评测，不能由导入或本地分数替代。
