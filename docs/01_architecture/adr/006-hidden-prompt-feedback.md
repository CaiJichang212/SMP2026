# ADR 006：用公开反馈识别隐藏话术，并独立估计收益

日期：2026-09-14。状态：P11 实验决策；提交启用另受独立统计与入口门禁控制。

## 问题与证据

FAQ Q4 明确话术编号为 `1,2,3`，对应的修正数值为黑盒。样例的
`{1:15,2:10,3:-5}` 不能充当正式常量。过去各提交固定话术 1，P8/P9 官方均为
`761.9467`；这暴露了实验覆盖不足，但不证明正式话术 1 一定较差。

公共自定义沙箱的 18 次跨话术观测支持同节点累计衰减 `1,0.5,0.25`，
所有归一化响应误差为零。原始观测见
[公共机制报告](../../../experiments/reports/p11-prompt-order-probe-20260914.json)。

## 识别规则

对节点 `i` 第 `t` 次沟通，记录公开的前值、成功返回的新值、话术编号与累计轮次。
未被意见边界截断时，首轮等效响应为：

`z(i,p) = (new_w - before_w) / decay(t)`。

在已检验的乘法机制 `z(i,p)=r(i)*strength(p)` 且 `r(i)>0` 下，
同一节点的三个 `z` 可比较话术强弱，节点系数会抵消。不需要也不能凭这些观测
分别恢复全局绝对话术强度和节点 `r`；将 `z/15` 解释为真实 `r` 是错误的。

P11 先选一个已扫描、未沟通、意见远离边界的和平或中立节点，按 `1,2,3` 探测。
有完整且可辨识的反馈就采用其最优编号；首节点无信息、截断或失败时才考虑第二节点。
最多两个参考节点、六次尝试、12 精神力；失败不推进成功轮次，不伪造预算扣减。
单节点证据标为 provisional，不标为经过两个节点确认。

## 必须保留的信息

- 负值与零都是观测，不能一律截成正数再用于话术排序。
- 两个最优话术并列时，选最小编号的已知最优话术，不能退回已知较差的话术 1。
- 全零参考节点可能只是该节点无响应，不能推断所有话术全局无效。
- 截断意味着完整响应不可识别；不能把触及上界的差值当作精确强度。
- 失败结果只记录失败，不更新成功反馈或节点沟通次数。

后续收益预测应使用所选话术的首轮等效响应，并随新的公开结果更新。记录以节点为
独立样本：同节点三个话术探测不算三个独立敏感度样本。不同话术的历史不可无条件
合并；P9 回退所需的话术 1 记录与新策略记录分离。预测值、校准结果及模型估计均放在
独立 ledger，不写入只保存公开事实的 Blackboard。

每个探测和后续干预都须先生成合法候选，由注入的 LLM 选择，单个 host step 最多一个
环境动作。模型失败采用合法候选的确定性回退；不读取环境私有字段、隐藏种子参数，
不在策略中主动结算。

## 如何判断值得提交

机制测试比较双方都做相同探测后的表现，只能验证编号学习是否有效。完整策略收益
必须相对原始、无探测的 P9 ZIP 计算，保留实际探索成本，并同时报告话术 1 本来最优
时的损失。改变同一图上的话术编号是配对干预，不产生新的独立图样本；置信区间按
图与重复编号组成的 block 聚合。

新分布须覆盖编号排列、幅度变化、零响应、并列、负值与截断。编号对称平均是声明的
实验分布，不是官方隐藏分布的已知事实。局部模拟收益不能换算成官方 `>900`，
已失败的门禁不能在看完数据后放宽再宣称通过。
