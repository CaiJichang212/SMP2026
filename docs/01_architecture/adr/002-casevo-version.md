# ADR-002：CaseVO 依赖与仓库边界

## 决策

`../casevo` 保持为独立 Git 仓库。`SMP2026` 仅记录其兼容性和已验证的提交版本，
不得向其中放入星网赛题策略、种子、提示词或成绩数据。

## 当前兼容性状态

Starter Kit 使用 `agent_mesa` 导入名，而本地源码仓库的包名为 `casevo`。提交环境应以
赛方评测镜像的实际依赖契约为准；本地环境不得仅为消除导入错误而替换或私自打包框架。

## 验证要求

每次更换框架版本或导入适配方式时，必须记录：CaseVO commit、Python 版本、安装命令、
可用导入名，以及一次干净环境中的提交包导入结果。
