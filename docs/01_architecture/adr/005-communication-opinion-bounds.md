# ADR-005：游说更新逐次截断倾向值

## 证据与范围

2026-09-13 的公开自定义沙盒探针发现，`w=100, r=1.5` 的节点执行话术 1
后仍返回 `new_w=100`，旧本地模拟器却得到 122.5。随后用 9 个初始值
`-110,-100,-99,-90,0,90,99,100,110`，两种响应系数 `0.2,1.5`，
话术 1 和 3，各连续游说三次，共收集 **108 次**公开返回。

所有返回都满足：

```text
new_w = max(-100, min(100, old_w + prompt_value * r * turn_multiplier))
```

截断模型的最大逐值误差为 **0**，旧无界模型最大误差为 **32.5**。
初始扫描不截断，截断发生在每次成功游说更新时。
原始公开响应和两种模型预测见
[探针数据](../../../experiments/reports/p9-response-bounds-probe-20260913.json)，
复现脚本为 `scripts/probe_response_bounds.py`。

这是公开沙盒的实测机制。它证明本地模型存在遗漏；尚不能证明正式隐藏样本触及了
该边界，也不能单独解释官方多次 761.9467 的总分。

## 决策

- 本地环境按实测机制逐次更新，供原样历史 ZIP 和新策略使用相同、正确的环境。
- 预测状态、候选实际增量、预算尾部槽位和多步推演都计入可用倾向空间。
  多个游说槽位必须共同消耗剩余空间，不能让每个槽位重复使用同一份空间。
- 虚拟动作也只能让虚拟策略学到截断后的返回增量。名义响应超过边界的部分是
  未观察量，不得把它当作公开首次响应或写进事实 Blackboard。
- 若增量不会触及边界，保留原来的算术路径和排序，避免无关的浮点重排。
- 原 P8 门禁不自动覆盖这一行为变化；单独冻结修正版本，比较原样 P8 ZIP，
  用饱和节点和饱和枢纽分布进行开发与独立确认，并保留历史官方最高分对照。

## 实验教训

P9 初始旧开发矩阵 22 族、501–503 的单节点最大可达值小于 65，重复这些样本
无法发现 100 附近的模型错误。新分布验证应按机制列出实际覆盖区间，而非只增加
随机种子数量。每次远端复放要检查公开响应误差；仅比较最终分数会掩盖这种偏差。
