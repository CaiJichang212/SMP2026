# P2 结算器扩展与重拟合：机制辨识结果（2026-09-06）

## 结论

P2 的原始阻塞已被定位：原 `degree` 候选把终局分近似为未归一的 `max(1, degree)` 加权和；它遗漏了**连通分量内的归一化**与 `degree + 1` 权重。新提出的候选评分器为：

$$
\widehat F(G,w)=\sum_{C\in\mathcal C(G)}
\frac{|C|}{\sum_{i\in C}(d_i+1)}
\sum_{i\in C}(d_i+1)w_i.
$$

这里每个连通分量 `C` 独立计算，孤立点自然得到自己的 `w_i`。这不是官方公式的声明，只是与公开 API 终局分高度一致的经验候选。

在新增的 29 个独立自定义会话中，所有会话可比、无协议/动作失败；候选的 MAE 为 `0.00094`，最大绝对误差为 `0.00429`（终局分服务端保留两位小数）。对已归档 V1 的 420 条结算记录进行**事后**回放，选择的模型为该候选，gate Spearman 为 `1.0000`、图级归一化 MAE 中位数为 `0.00182%`。

但这仍然**不通过 P2 晋级**：候选是在先前 5% 门禁失败后才提出，而 V1 的 calibration / selection / gate 三个 split 重复使用了所有图族，仅改变意见布局，不是拓扑留出。代码现已把“真实拓扑留出”设为必需门禁；因此重新分析仍明确返回 `gate_passed=false`。`DEFAULT_CALIBRATION_PROFILE` 未写入任何参数，B2–B5 继续失效关闭，提交默认继续为无 LLM 的 B1。

机器可读摘要在 [`p2-settlement-refit-mechanism-v2-20260906.json`](../../experiments/reports/p2-settlement-refit-mechanism-v2-20260906.json)，原始响应在被忽略的 `experiments/raw/`。

## 预注册问题与设计

此前未通过门禁的图族是 `path5`、`triangle`、`star5`。本轮 P2.1 不比较策略，也不调整任何运行时阈值；它只回答以下可证伪问题：

1. 固定拓扑上，终局分是否对单节点初始倾向近似线性？
2. 相同倾向脉冲在路径端点/内部、星形中心/叶子、三角形顶点的灵敏度是否不同？
3. 切边、屏蔽和游说后，重新按连通分量计算的候选是否仍与终局分一致？

清单 [`p2-settlement-refit-mechanism-v2.json`](../../experiments/manifests/p2-settlement-refit-mechanism-v2.json) 固定 29 个 fresh session：

| 区块 | 会话数 | 控制/干预 |
| --- | ---: | --- |
| `path5` 线性脉冲 | 7 | 零值；端点、近端、中心各 `+10/-10` |
| `triangle` 线性脉冲 | 3 | 零值；一个顶点 `+10/-10` |
| `star5` 线性脉冲 | 5 | 零值；中心、叶子各 `+10/-10` |
| 结构反事实 | 9 | 路径外/内切边与端点/中点屏蔽；三角形切边/屏蔽；星形切边、中心/叶子屏蔽 |
| 游说反事实 | 5 | 路径端点/中心、三角形顶点、星形中心/叶子各一次 `prompt_id=1` |

每次先用公开 `scan_node()` 扫描整张微图，只执行清单中至多一个合法动作，再由**本地实验 runner**调用 `trigger_eval()`。提交模型不会调用 `trigger_eval()`、不会读取种子的 `r`，也不会访问环境私有字段。缺失、协议异常、动作失败、扫描快照不一致或非有限分数均判为不可比，不插补。

## 重拟合与门禁审计

该候选已作为 `component_degree_plus_one` 加入离线 `SettlementPredictor` 的候选族，且保留默认关闭。对归档 V1 记录的本地重分析结果为：

| split | MAE | 图级归一化 MAE 中位数 |
| --- | ---: | ---: |
| calibration | `0.00061` | `0.00179%` |
| selection | `0.00067` | `0.00099%` |
| gate | `0.00066` | `0.00182%` |

数值误差均可由终局分两位小数的舍入解释。过去的 `degree` 族在相同 gate 上为 `10.24%`，所以公式修正确实解决了已观察到的长路径、三角形和星形误差，而不是放松阈值。

为防止事后模型选择被误当作验证，`scripts/calibrate_v1.py` 现在检查 split 的拓扑族是否相交。历史 V1 的三组都包含 `isolated/edge/path3/path5/triangle/star5/disconnected`，故 `topology_held_out=false`；即使数值门槛满足，也不得产生可用档案。

## P2.1 完成时预注册的 P2.2 方案（已执行）

以下内容保留 P2.1 完成时的预注册计划；P2.2 已按该方案执行，结果见
[`p2-topology-holdout-v2-20260906.md`](p2-topology-holdout-v2-20260906.md)。

应重新预注册并采集新的、重复的校准矩阵，再决定是否冻结。建议按拓扑族而非意见布局切分：

| split | 建议图族 | 目的 |
| --- | --- | --- |
| calibration | `path4`, `star4`, `square` | 只拟合已提出的分量公式与舍入容差 |
| selection | `path6`, `star6`, `triangle_tail` | 选择固定模型族，不读 gate 分数 |
| gate | `path7`, `star7`, `bow_tie`（双三角共享顶点） | 验证更长路径、不同分支及含环图的泛化 |

每族使用至少三种独立意见布局、四种单动作（control / comm / cut / shield）和五个 fresh session 重复；结构动作应覆盖端点与内部/中心与叶子等轨道。仍使用 `Spearman ≥ 0.90`、归一化 MAE 中位数 `≤ 5%`，并新增：所有三个 gate 图族的均值 MAE 都须 `≤ 5%`、无新增协议/动作失败、拓扑集两两不相交。通过后还要独立校验结构动作收益，才可讨论 B3/B4；P3 仍排在 P2 后。
