# P2.3 v8 公开结构风险门实验（2026-09-08）

## 变更

v8 只改变显式 `PUBLIC_GREEDY` 实验分支，默认提交仍是无 LLM 的 B1。结构动作不再
等待四个首轮响应：扫描得到的拓扑和 `w` 已足以直接重算屏蔽/切边的公开终局增益，
因此 `min_observed_responses=0`，结构 ROI 与当前最佳游说 ROI 按 1.0 比较。

在强正向公开图（非负/和平节点占比至少 0.85，且正向质量至少为暴力负向质量的
2 倍）上，结构动作关闭，响应选择保留 B1 的 pooling 路径。其他图使用固定的 12.75
首轮人口先验；已尝试节点只使用自己的公开首轮 `new_w`，不把单个观测传播给未尝试
节点。12.75 仅是离线先验，不是环境字段；运行时不读取 `r`。

结构候选扩展为公开 `w < 0` 且人设非“和平”的节点；切边要求另一端不是同样的公开
负向非和平节点。所有候选仍需通过预算、节点、边、通信次数和 prompt 校验。

## 远端公开协议核验

官方公开沙盒四节点自定义 seed：v8 `public_greedy` 得分 `124.61`，扫描快照匹配，
零动作失败；与历史 B1 `87.38` 的方向一致。一个公开生成 50 节点 `er_balanced`
seed 的 v8 远端得分为 `802.81`，扫描快照匹配、零失败，与本地对应 seed 的
`802.8063` 一致（仅显示精度不同）。这些是自定义 seed 结果，不能直接替代平台隐藏
多种子榜单评测。

## 结论

v8 保留了强正向网络上的 B1 基线，同时在负向拓扑上释放可由公开状态直接验证的
结构收益；相较 v5 的“等待四次响应、1.25 倍 ROI”门，独立 block 的平均差提升，
且未引入动作失败。下一步交付显式 v8 实验 ZIP 供平台新窗口评测；平台提交结果是
是否达到 `>900` 的唯一直接证据。
