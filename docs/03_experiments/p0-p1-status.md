# P0/P1/P2 implementation status

## P0 status: transport and fixed-terminal stability passed; P2.2 settlement gate passed

On 2026-09-06, the public `RemoteStarNetEnv` path was run through the
pre-registered 20-session fixed-terminal gate from a network path able to
reach the official sandbox. All 20 sessions were comparable, with zero
protocol/action failures, matching scan/final-state hashes, and zero score
spread for each of the four fixed action sequences. The reviewed summary and
raw-result location are recorded in
[`p0-p3-experiment-plan-and-local-results-20260906.md`](p0-p3-experiment-plan-and-local-results-20260906.md).

The 2026-09-05 diagnostic probe failures remain historical evidence about a
restricted execution network, not a reason to reject the successful P0 gate.
They do not calibrate response or settlement parameters. The original
135-session response table and 420-session V1 settlement cohort were
completed with 555/555 comparable sessions; the old `degree` model met the
ranking condition (gate Spearman 0.9543) but failed the preregistered
normalised-MAE condition (10.24% > 5%). That is a historical fail-closed
result, recorded in [`v1-calibration-20260906.md`](../../experiments/reports/v1-calibration-20260906.md).

The follow-up P2.2 topology-held-out cohort completed 540/540 comparable
sessions with zero protocol/action failures. The selected
`component_degree_plus_one` model passed the independent gate (Spearman
1.0000, median normalised MAE 0.00553%, worst family mean 0.01032%). This
qualifies the offline settlement predictor, not the runtime strategy: the
default profile still has no literal influence archive and
`structure_gate_passed=false`. Details are in
[`p2-topology-holdout-v2-20260906.md`](p2-topology-holdout-v2-20260906.md).

`DEFAULT_CALIBRATION_PROFILE.gate_passed` therefore remains false and contains
no frozen influence coefficients. B2 remains ineligible, and no `cut` or
`shield` candidate can be generated by the default submission path.

The next registered step is P2.3, which injects the reviewed P2.2 report only
into an offline runner and compares B3/B4 against B1 on 24 large-graph seed
blocks. It must not modify the submission default. The matrix is recorded in
[`p2-structure-policy-matrix-v3.json`](../../experiments/manifests/p2-structure-policy-matrix-v3.json).

```bash
uv run python scripts/run_experiments.py \
  --manifest experiments/manifests/p2-structure-policy-matrix-v3.json \
  --experimental-calibration-report experiments/reports/p2-topology-holdout-v2-20260906.json \
  --dry-run
```

The historical calibration script keeps all candidate families explicit and
still fails closed when a report is incomplete, not topology-held-out, or does
not pass its gate.

## P1 status: B1 implemented; B2 ineligible

The submission explicitly selects the preliminary `StageSpec` (50 nodes, 100
budget, 120 Step/LLM limits; local stop caps 117/115). It scans every legal ID
before considering any intervention, then uses B1's observed-degree × response
estimate to choose one legal `communicate` slot at a time. Public `new_w` and
`comm_left` update the Blackboard and rebuild the next-slot ordering. Unknown
`comm_left`, insufficient budget, no positive gain, and safety caps stop
without calling `end_turn`.

B2 needs a verified literal calibration profile with held-out per-target
influence coefficients. The profile is deliberately empty, so selecting B2
falls back to B1 and must be reported as ineligible rather than scored.
