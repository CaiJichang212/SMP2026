pre-registered 20-session fixed-terminal gate from a network path able to
reach the official sandbox. All 20 sessions were comparable, with zero
protocol/action failures, matching scan/final-state hashes, and zero score

[`p0-p3-experiment-plan-and-local-results-20260906.md`](p0-p3-experiment-plan-and-local-results-20260906.md).

135-session response table and 420-session graph-held-out calibration were
completed with 555/555 comparable sessions. The selected degree model met the
ranking condition (gate Spearman 0.9543) but failed the preregistered
normalised-MAE condition (10.24% > 5%). The reviewed result is
[`v1-calibration-20260906.md`](../../experiments/reports/v1-calibration-20260906.md).

`DEFAULT_CALIBRATION_PROFILE.gate_passed` therefore remains false and contains
no frozen influence coefficients. No `cut` or `shield` candidate can be
generated by the submission.

After rechecking connectivity, continue the unmodified calibration protocol with:

```bash
uv run python scripts/preflight_runtime.py
uv run python scripts/run_p0_probes.py --manifest experiments/manifests/v1-local-probes.json
uv run python scripts/analyze_p0_probes.py --raw <raw-results.jsonl> --report <report.md>
```

Only a full comparable cohort advances to the pre-registered response and
settlement experiments in `v1-calibration.json`. The calibration script keeps
all three candidate families (degree, self-retaining DeGroot, and
Friedkin–Johnsen) explicit and fails closed when its held-out gate does not
pass.

without calling `end_turn`.

influence coefficients. The profile is deliberately empty, so selecting B2
