# P0/P1 implementation status

## P0 status: blocked, not calibrated

The frozen ten-probe availability check was most recently rerun on 2026-09-05
with fresh sessions. Only 1/10 sessions was comparable; the other nine had
public SDK protocol failures at `/get_budget` or `/scan`. The controlled probe
results and failure summary are versioned in `experiments/reports/`; raw
responses remain ignored under `experiments/raw/`.

This fails the 10/10 availability gate before the required 20 fixed-terminal
stability sessions and the seven §5.1 micro-experiment families can be
interpreted. `DEFAULT_CALIBRATION_PROFILE.gate_passed` is therefore false and
contains no frozen influence coefficients. No `cut` or `shield` candidate can
be generated by the submission.

After service recovery, run the unmodified probe manifest with:

```bash
uv run python scripts/preflight_runtime.py
uv run python scripts/run_p0_probes.py --manifest experiments/manifests/v1-local-probes.json
uv run python scripts/analyze_p0_probes.py --raw <raw-results.jsonl> --report <report.md>
```

Only a full comparable cohort advances to the pre-registered response and
settlement experiments in `v1-calibration.json`. The calibration script keeps
all three candidate families (degree, self-retaining DeGroot, and
Friedkin–Johnsen) explicit and fails closed when its held-out gate does not
pass.

## P1 status: B1 implemented; B2 ineligible

The submission explicitly selects the preliminary `StageSpec` (50 nodes, 100
budget, 120 Step/LLM limits; local stop caps 117/115). It scans every legal ID
before considering any intervention, then uses B1's observed-degree × response
estimate to choose one legal `communicate` slot at a time. Public `new_w` and
`comm_left` update the Blackboard and rebuild the next-slot ordering. Unknown
`comm_left`, insufficient budget, no positive gain, and safety caps stop
without calling `end_turn`.

B2 needs a verified literal calibration profile with held-out per-target
influence coefficients. The profile is deliberately empty, so selecting B2
falls back to B1 and must be reported as ineligible rather than scored.
