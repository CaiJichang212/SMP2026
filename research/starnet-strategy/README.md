# 星网策略研究

研究目标：设计、测试并交付符合规则的 CaseVO/agent_mesa 星网智能体，尽量提高
官方隐藏种子的平均援助意愿得分。依据为 `docs/task/` 和原始
`SMP_Starter_Kit/`；最终交付物是放在 `submissions/` 中、经过验证的提交 ZIP。
已完成规格、公开沙盒基线/替代方案比较及决策；正式实现及10/50/100节点真实LLM提交包验证已完成，官方隐藏验收待用户平台操作。
研究证据不等同于官方隐藏种子成绩。

约束：主机仅有 2 vCPU、约 4 GB 内存；初赛和复赛精神力预算分别为 100 和 200，
步数与大模型调用数分别受 120/250 次上限约束；隐藏种子为黑盒，核心决策须有
大模型真正参与，只能使用规定的环境接口。主要风险：示例代码中过时的 50 步限制、
本地 `casevo` 与线上 `agent_mesa` 的兼容性、远端服务可用性、密钥泄漏、
资源耗尽及对样例种子过拟合。
