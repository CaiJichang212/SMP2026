# Specify 结果
- 输入：仅 get_remaining_budget、scan_node、communicate、cut_link、shield_node 的公开反馈；注入 llm 与 person_list。
- 输出：ParticipantSquadModel.step 返回0继续、1停止；每步至多执行一个环境动作；最终ZIP仅config.json/prompt/starnet_model.py。
- 合规：ModelBase/AgentBase、经框架 Prompt 调用 LLM；所有执行动作均须来自LLM选择或其有界批次计划。无LLM的算法仅作实验对照。
- 预算：120/250 步和调用分别计数；失败调用也计数；初始非标准预算使用保守120上限。动作前重验余额与有效性。
- 话术：不预设最强编号、强度、人设系数；在同节点按已使用次数归一化反馈进行相对比较，标记跨节点估计的不确定性。
- 成功门槛：多拓扑、多符号、多话术排列的公开自建种子；分别记录官方沙盒自然分、干预分、差值、预算、步数、LLM调用、时间、内存。
- 本地候选准入：同种子平均得分>=无干预，不发生越权、非法动作或超限；真实LLM至少端到端跑通小图及50节点样本。泛化结论不外推到官方隐藏种子。
- 边界：空反馈、None、JSON异常、超时、未知节点、无通信次数、负向话术、断连图、预算不足、LLM失败。失败不自动改用硬编码干预。
- 初次远端探针（2026-09-18）：start=200，预算60；scan1返回comm_left=3及邻居；communicate(1,1)返回new_w=32.5；结算7.5。仅链路证据。
- 缺失：线上旧agent_mesa安装版本、隐藏种子、天池提交凭证；这些不能由本地测试代替。
