# B1 在线响应先验敏感性筛选（2026-09-07）

## 范围与边界

本筛选只比较无 LLM、无 `cut`/`shield` 的 B1 游说分配。运行时策略只读取扫描和
`communicate` 的公开返回；本地模拟器以受版本控制的自定义 seed 产生同构的游说
反馈和 `component_degree_plus_one` 结算，seed 内的 `r` 只用于模拟环境，不进入
Blackboard 或策略输入。因此结果用于选择 B1 的稳定默认，不是隐藏榜单分数，也不构成
启用结构策略的证据。

矩阵为六个生成拓扑族、`50/100` 节点、每族每规模五次重复，共 60 个 session。比较
未试节点响应先验的 P1 `+15` 伪观测权重；已试节点始终使用本节点的公开首轮响应及
`1, 1/2, 1/4` 衰减。

## 结果

| 伪观测权重 | 平均终局分 | 最低终局分 |
| ---: | ---: | ---: |
| 0 | 742.616 | -226.135 |
| 1 | 742.428 | -226.135 |
| 3（当前） | 742.581 | -226.135 |
| 5 | 742.742 | -226.135 |
| 10 | 742.499 | -226.135 |

`3` 与本矩阵最高的 `5` 相差仅 `0.161`（60 个异质 session 的均值），没有可支持的
稳定排序；不应为了这一差值反复调参。保留 `3`，因为它在首轮样本极少时提供适度收缩，
同时会随公开响应迅速让数据主导。

族级均值显示 B1 在 `sbm_violent_cluster` 上仍明显较弱（所有权重约 `5–8`）。这表明
瓶颈是高风险负簇的拓扑干预，而非响应先验的细微选择。依据当前策略门禁，不能将这一
观察直接用来开启 `cut`/`shield`；只有新的、拓扑不相交的结构策略验证通过后才可改变
提交默认路径。
