# 2026-09-12 公开结构策略、LLM 决策与扫描消融

## 实验设计

使用同一自定义种子配对比较 B1 全扫描和公开状态结构风险门策略。独立拓扑 block 包含 `grid_lattice`、`cycle_chords`、`two_block_bridge`、`tree_broom`，50/100 节点各 3 次重复。每个动作只通过公开 API；本地环境内部保留未公开响应系数 `r`，策略只收到扫描与动作返回。本地终局使用此前通过拓扑留出校准的 `component_degree_plus_one` 结算器。族均值为 bootstrap 单位，记录失败数、结构动作和调用数。设计与筛选条件见 [`p2-public-llm-adaptive-20260912.json`](../manifests/p2-public-llm-adaptive-20260912.json)。

LLM 契约臂使用遵守相同 JSON 模式的确定性模型替身，仅检验调用上限、候选合法性和执行轨迹，不评估真实模型的策略质量。真实模型另在赛方公开四节点自定义种子上核验。扫描消融在扫描 80% 节点后，根据已公开的暴力负向占比与正向图门决定是否提前停止；该变体必须在独立和既有拓扑上都通过非负族级差值才可晋级。

## 结果

独立 block 的公开结构策略相对 B1：50 节点四族均值从 `561.98` 提至 `637.75`；100 节点从 `1125.92` 提至 `1270.76`。按拓扑族平均的配对增益为 `+110.31`，10,000 次 bootstrap 的 95% 区间为 `[+9.83, +290.22]`，全部 48 个 B1/结构 session 零动作失败。详细逐种子结果见 [`p2-public-greedy-llm-mock-independent-20260912.json`](p2-public-greedy-llm-mock-independent-20260912.json)。

在同一 24 个种子上，模型替身参与每次扫描和干预的候选选择，终局分与确定性公开结构策略逐种子完全相同，零动作失败。50 节点的平均模型调用数按拓扑族为 `73.33–87`，100 节点为 `147.67–175`，均低于 120/250 次公开熔断限额；真实模型可能选不同候选，因此这不是其得分估计。

赛方公开四节点自定义种子的完整真实 LLM 跑测得到 `124.61`，14 次模型调用、14 次动作成功、零失败，扫描快照与种子一致。另一次限五步的协议核验中，真实模型的 5 次输出全部通过候选和证据校验，包括扫描与首个干预动作；该限步得分 `27.86` 不作为完整策略成绩。

扫描消融在独立 block 上相对公开结构策略平均 `+4.55`，但 `tree_broom` 100 节点为 `−11.26`。在既有六族 50 节点验证 block 上平均 `−38.41`，`ba_negative_hubs` 为 `−166.76`，`er_balanced` 为 `−27.04`，`sbm_negative_bridges` 为 `−36.64`。故该变体未通过晋级门，不进入提交包。数据见 [`p2-adaptive-scan-independent-20260912.json`](p2-adaptive-scan-independent-20260912.json) 和 [`p2-adaptive-scan-existing-20260912.json`](p2-adaptive-scan-existing-20260912.json)。

## 结论与下一步

保留全扫描公开结构风险门，并将显式实验包改为单个真正发起 CaseVO Prompt 调用的智能体：Python 生成合法候选，模型对每次扫描和干预作最终选择；超时、非法输出或配额耗尽时按已校验候选确定性回退。失败切边/屏蔽后的预算以公开预算查询为准，不依据动作成功与否虚构扣费。

目标 `>900` **尚未证实**。本地 50 节点独立 block 均值为 `637.75`；跨 50/100 节点混合均值不能充当初赛榜单分。公开四节点种子也不能推断隐藏种子的平均分。当前用户提供的最高平台成绩仍为 `765.84`，新实验 ZIP 尚无平台成绩。下一轮应以平台新窗口成绩作为主判据，并重点实验多边切断的组合收益以及负向枢纽拓扑的结构动作筛选；每次仍用未参与调参的拓扑族配对验证，避免把有利种子分布误当成泛化提升。
