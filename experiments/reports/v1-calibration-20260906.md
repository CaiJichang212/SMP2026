## P2 图留出校准

校准集拟合每个模型族，选择集只在已冻结的族内候选选择模型，gate 集完全留出。三个候选族在选择集上的 Spearman 都较高，选中的 degree 聚合模型在 gate 的排序相关仍为 `0.9543`，满足预注册的 `≥0.90` 要求；但是图级动作范围归一化 MAE 中位数为 `10.24%`，未满足 `≤5%`。

| gate 条件 | 阈值 | 实测 | 结果 |
| --- | ---: | ---: | --- |
| 响应先验覆盖 | 全部 key、每 key ≥5 | 全部 27 key、每 key 15 | 通过 |
| 结算 action/split/repeat 覆盖 | 21 图 × 4 动作 × 5 | 420 / 420 | 通过 |
| 终态重复稳定性 | 相对跨度 ≤2% | 所有 gate 终态为 0 | 通过 |
| gate Spearman | ≥0.90 | 0.9543 | 通过 |
| gate 图级归一化 MAE 中位数 | ≤5% | **10.24%** | **失败** |

误差集中在较长或高度连通的拓扑：`path5=47.31%`、`triangle=47.49%`、`star5=84.74%`；`edge`、`isolated`、`disconnected` 为 0。这表明当前 degree 聚合能大致排序动作，却系统性低估负桥图中的绝对分数，不能安全用作结构动作 ROI。

## 决策

`CalibrationProfile.gate_passed=false`，且结构资格仍为 false。因此：

- 不冻结或写入默认 calibration profile；B2/B3/B4 继续退回 B1。
- 不运行或解释 P3 的 B5 自适应探索/LLM 主矩阵；它依赖已通过的结构和 scenario 门禁。
- 保持无 LLM 的 B1 提交默认。P0/P1/P2 的本地和远端事实不构成隐藏 seed 上的策略排名。

## 下一轮改进建议

1. 扩展结算器族，而不是放宽 5% 门槛：对 `path5`、`triangle`、`star5` 记录多种权重布局和单动作响应，用实际收敛方程/权重重拟合，再作新的图留出验证。
2. 为结构动作单设可泛化的影响表征。当前按 node ID 的 `target_influence` 不能直接从小图迁移到隐藏 seed；需要由公开扫描图实时计算、并在独立图族上验证的影响特征及误差界。
3. 在 P2 通过前不要用 P1 的确定性 response 表启用 CMG：它只解决游说幅度，未解决拓扑变化的终局评分误差。
4. P3 的 scenario profile 应以独立、未参与结算器选择的隐藏结构样本校验；不能用本轮 21 个微图或终局标签生成线上情景。
